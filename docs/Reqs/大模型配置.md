# 大模型配置
在openclaw里，有官方预设的供应商。也可以自定义，对于自定义，需要直接修改openclaw.json
所以，为了通用，全部模型配置用openclaw.json直接修改

在openclaw初始配置里，除了大模型，其他步骤全部选择激活。等待初始化完成。

在信息收集页里，同一个供应商的不同套餐，应该作为不同选项出现，例如
- deepseek
- z.ai-coding-plan
- z.ai

从信息收集页里将选中的供应商/套餐，以及API key，完善openclaw.json

## deepseek

当用户在信息收集页里选中deepseek后，需要展示deepseek获取API key的网址，指引用户登录网址获取：https://platform.deepseek.com/api_keys

### 示例openclaw.json
{
  "models": {
    "providers": {
      "volcengine-plan": {
        "baseUrl": "https://api.deepseek.com/v1",
        "apiKey": "<ARK_API_KEY>",
        "api": "openai-completions",
        "models": [
          {
            "id": "deepseek-reasoner",
            "name": "deepseek-reasoner",
            "contextWindow": 256000,
            "maxTokens": 128000,
            "input": [
              "text",
              "image"
            ]
          }
        ]
      }
    }
  },
  "agents": {
    "defaults": {
      "model": {
        "primary": "deepseek-reasoner"
      },
      "models": {
        "deepseek-reasoner": {}
      }
    }
  },
  "gateway": {
    "mode": "local"
  }
}
