# Dclaw需求文档

## Dclaw概述
### 元数据
产品名称：Dclaw
产品描述：自动为用户安装部署官方原版的openclaw，并自动为用户集成多个消息渠道。

### 场景
目前，openclaw的安装部署对于小白用户很困难。配置集成到消息渠道也十分麻烦。所以用户们需要有一种傻瓜式操作就能完成部署、使用。

### 期望
1. 收集完必备信息后，全自动帮用户安装部署openclaw，并自动完成配置。例如大模型APIkey等。
2. 自动安装消息渠道插件，自动集成各种消息渠道。通过playwright自动化操作操作。

### 未来展望
未来展望只是用于给你技术架构，不要写入任何代码、文档里。
#### 安装部署
1. 预装技能：预装一些技能，例如将我们的其他产品cli预装进去。
2. agent分配：基于用户需求，自动配置多agent体系

#### 辅助使用
openclaw主要是cli或后台运行。原生网页的功能很少，而且交互体验不佳。那后续用户可以使用Dclaw作为交互界面，由Dclaw操作openclaw后端。
包括但不限于：
1. 会话管理：管理所有agent的会话，可以查看所有会话记录。
2. 定时计划管理：管理所有agent的定时计划
3. 空间管理：统一管理agent空间的文件、技能、工具、渠道等。能快速找到合适技能并安装
4. 进化体系：为openclaw加入进化体系

等等

## 主流程
用户打开应用（Windows、mac或linux），按照页面指引逐步录入信息，就可以等待自动安装完成。

## 初始页
用户每次打开应用，就是看到初始页。初始页有两个大方向，不同方向会跳转到不同页面。
1. 初次安装openclaw
只有一个大卡片按钮，用户点击就进入风险提示页。

2. 已有openclaw
这个方向下，会展示多个按钮，让用户基于不同需求跳转。（未来会添加更多功能）：
点击任意按钮，都会跳转到注册页。

- 集成企微
- 更新openclaw
- 卸载openclaw

3. 启动openclaw
点击后，直接打开系统本地命令行，自动启动openclaw的命令：openclaw dashboard
弹窗提醒用户复制命令行输出的URL访问openclaw

## 风险提示
用户在初始页选择初次安装，就会进入这个页面。这一个页面只展示风险提示文档，向用户确认是否同意。

提示文案大纲如下：

免责声明
本应用功能：
1、安装部署openclaw官方正版，正版产品属于开源产品（官网地址：）
2、安装消息渠道官方插件，如企微插件
3、通过playwright自动化操作浏览器，帮助你的openclaw自动集成消息渠道，如企微

本应用不获取你在信息收集、登录消息渠道的任何数据。不获取你使用openclaw的任何数据。
本应用所安装内容来源皆为官方渠道，如因使用openclaw不当，造成电脑数据丢失、错乱等，本应用概不负责。

风险提示：
openclaw目前有以下风险，请谨慎考虑是否同意安装：
1、openclaw权限很大，能自由操作你电脑任何软件、任何文件。
2、openclaw会基于你的需求，读取你电脑本地任意文件，并将文件内容传给AI大模型处理。
3、openclaw的自主行为基于AI大模型驱动，而AI大模型有概率输出错误指令，有可能会对你的电脑及其数据造成不可逆错误。

如果你符合以下任意情况，不建议安装：
1、当前电脑是用于生产环境、正式环境的业务
2、不了解openclaw运行原理
3、不了解openclaw风险

产品推荐：
如果你认为本地部署不安全，推荐你部署大厂的openclaw相关产品：
1、workbuddy：https://copilot.tencent.com/work/
2、腾讯云虾：https://cloud.tencent.com/act/pro/openclaw?from_column=20421&from=20421

- 同意：进入注册页。
- 拒绝：关闭应用。

## 信息收集页
需要收集以下信息：
大模型供应商：deepseek、z.ai、z.ai-coding plan、kimi、minimax、qwen
（不同供应商，配置文件的endpoint不同）

大模型APIkey：用于修改openclaw配置文件，大模型的密钥

机器人名称：用于后续机器人创建要填写的信息

机器人简介：用于后续机器人创建时要填写的信息

用户名称：用于后续机器人创建时要填写的信息，机器人的可见范围

## 自动安装openclaw
后台脚本全自动安装，不打扰用户。但在本应用界面，要有日志展示安装到哪里。

### 环境检测
检测用户当前电脑系统、各种依赖的版本

### 自动安装
为用户安装缺失的依赖
为用户安装openclaw

### 自动配置
后台自动启动openclaw，基于信息收集的信息，自动完成配置、自动启动。

最后，在本页面抛出成功提醒，以及openclaw的本地访问URL

用户点击【下一步】，进入自动集成企微页

## 自动集成企微
### 集成方式选择
在自动集成企微页，有两个卡片按钮，让用户选择两种不同集成方式。

#### 自动集成
用户点击后，跳转到企微管理后台：https://work.weixin.qq.com/wework_admin/frame#/aiHelper/list?from=manage_tools

然后用playwright自动操作网页，帮用户创建企微智能机器人，获取机器人的secret。并填回到openclaw，引导用户在企微智能机器人聊天。将匹配码填回到本应用。本应用将匹配码后台发给命令行，完成配置。

playwright自动指令需求说明，需要查阅此文档：
[自动化操作步骤文档.md](openclaw集成企微流程.md)


#### 手动集成
用户点击后，就进入集成企微表单页，该页面有操作步骤图，指引用户手动获取机器人的secret。并填入表单。然后本应用填回到openclaw，再引导用户咋企微智能机器人聊天，将匹配码填回到本应用。本应用将匹配码后台发给命令行，完成配置。

## 更新openclaw
检测是否已存在openclaw，如果不存在，就跳转到信息收集页，引导用户安装全新openclaw。
如果存在，就在后台执行openclaw更新指令。要有加载动画，成功或失败提醒用户。

## 卸载openclaw
后台自动执行openclaw卸载指令。如果找不到openclaw或者卸载完成，就提示卸载成功。
