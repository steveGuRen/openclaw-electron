# Dclaw 产品设计文档

## 产品概述
Dclaw是一款自动化openclaw安装部署工具，为小白用户提供一键式安装、配置和消息渠道集成能力，降低openclaw的使用门槛。

### 核心功能
- 全自动安装部署openclaw官方原版
- 自动检测和安装所有前置依赖（Node.js、git等）
- 引导式配置大模型API Key和机器人信息
- 自动化集成企微等消息渠道（支持自动/手动两种方式）
- 提供openclaw更新、卸载、启动等管理功能

## 技术栈
| 层级 | 技术选型 | 说明 |
|------|---------|------|
| 桌面容器 | Electron 29+ | 跨平台桌面应用支持 |
| 前端框架 | Vue 3 + Vite | 现代化前端开发体验 |
| UI组件库 | Element Plus | 开箱即用的桌面端UI组件 |
| 状态管理 | Pinia | Vue 3官方状态管理方案 |
| 自动化 | Playwright | 浏览器自动化操作企微后台 |
| 打包工具 | electron-builder | 多平台打包和分发 |

## 架构设计
采用Electron经典的主进程/渲染进程分离架构，结合独立工具进程，遵循安全最佳实践和单一职责原则。

### 进程职责
1. **渲染进程 (Vue 3 SPA)**
   - 负责所有用户界面展示和交互
   - 表单数据收集、验证和状态管理
   - 安装进度、实时日志展示
   - 页面路由跳转和用户引导
   - 不直接执行任何系统级操作

2. **主进程 (Electron Main)**
   - IPC通信路由和进程协调调度
   - 窗口管理、系统交互和菜单配置
   - 全局状态管理和持久化
   - 操作互斥锁管理，防止并发操作冲突
   - 不直接执行耗时操作，仅负责调度到对应子进程

3. **工具子进程 (独立进程)**
   - **系统操作子进程**: 负责命令执行、文件读写、openclaw安装/更新/卸载等耗时操作
   - **Playwright子进程**: 独立管理浏览器自动化实例，负责企微自动集成操作
   - 子进程独立运行，异常退出不会影响主进程和UI稳定性

### IPC通信协议
#### 渲染进程 → 主进程调用事件
| 事件名 | 参数 | 说明 |
|-------|------|------|
| `deps:check` | - | 检测系统依赖情况 |
| `deps:install` | - | 自动安装缺失依赖 |
| `openclaw:install` | InstallConfig | 开始安装openclaw |
| `openclaw:update` | - | 更新现有openclaw |
| `openclaw:uninstall` | - | 卸载openclaw |
| `openclaw:start` | - | 启动openclaw dashboard |
| `integration:auto:start` | - | 开始企微自动集成 |
| `integration:manual:submit` | IntegrationConfig | 提交手动集成配置 |

#### 主进程 → 渲染进程通知事件
| 事件名 | 参数 | 说明 |
|-------|------|------|
| `deps:progress` | ProgressState | 依赖安装进度更新 |
| `deps:log` | LogEntry | 依赖安装实时日志 |
| `deps:success` | - | 依赖安装成功 |
| `deps:error` | ErrorInfo | 依赖安装失败 |
| `install:progress` | ProgressState | 安装进度更新 |
| `install:log` | LogEntry | 安装实时日志 |
| `install:success` | { accessUrl: string } | 安装成功，返回访问地址 |
| `install:error` | ErrorInfo | 安装失败 |
| `integration:step` | { step: number, total: number, message: string } | 集成步骤更新 |
| `integration:success` | - | 集成成功 |
| `integration:error` | ErrorInfo | 集成失败 |

## 页面结构
| 路由路径 | 页面名称 | 功能说明 |

| `/` | 初始页 | 三个入口：首次安装、已有openclaw、启动openclaw |

| `/integration` | 集成方式选择页 | 自动集成/手动集成选项 |
| `/integration/auto` | 自动集成页 | Playwright自动化操作企微后台 |

### 页面跳转逻辑
1. **首次安装流程**: 初始页 → 风险提示页 → 信息收集页 → 依赖安装页 → openclaw安装页 → 集成选择页
2. **已有openclaw流程**:
   - 集成企微 → 集成选择页
   - 更新openclaw → 更新页
   - 卸载openclaw → 卸载页
3. **启动openclaw**: 直接执行命令，弹窗提示访问地址

## 核心功能模块
### 1. 依赖管理模块
#### 环境检测
- 系统兼容性检测：明确支持Windows 10+/macOS 11+/Ubuntu 20.04+及以上版本
- 依赖版本检测：Node.js >= 24.0.0、git >= 2.30.0
- 系统资源检测：至少2GB可用磁盘空间、2GB可用内存
- 已安装openclaw实例扫描：检测系统中是否已有openclaw安装，避免冲突

#### 自动安装策略
- **权限友好设计**: 默认安装路径选择用户目录（%APPDATA%/Dclaw、~/.dclaw），不需要管理员权限
- **依赖安装优先级**:
  1. 优先使用系统已安装的符合版本要求的依赖
  2. 如系统无符合要求的依赖，自动下载官方便携版安装到Dclaw专属目录
  3. 不修改系统环境变量，所有依赖仅在Dclaw内部使用，不影响系统其他软件
- **多版本兼容**: 支持Node.js多版本共存，不会修改系统默认Node.js版本
- **包管理器优先级**: pnpm > yarn > npm，自动选择最快的包管理器

#### 系统兼容性处理
- **Windows**:
  - 自动处理UAC权限提示，仅在必要时申请管理员权限
  - 支持便携版安装，所有文件都在同一目录，可直接拷贝使用
  - 自动处理Windows Defender可能的误报提示
- **macOS**:
  - 自动处理sudo权限申请
  - 适配Apple Silicon和Intel芯片
  - 处理Gatekeeper安全性设置提示
- **Linux**:
  - 适配Debian/Ubuntu、CentOS/RHEL、Arch等主流发行版
  - 自动识别系统包管理器（apt、yum、pacman等）
  - 处理sudo权限申请和目录权限问题

#### 安装冲突处理
- 安装前扫描系统中已存在的openclaw实例
- 如果存在，提供三个选项：
  1. 升级现有安装实例
  2. 创建新的独立安装实例（支持多实例共存）
  3. 取消安装
- 多实例管理：支持用户切换和管理多个独立的openclaw实例

### 2. openclaw管理模块
- **安装**: 克隆官方仓库 → 安装依赖 → 写入配置 → 初始化启动
- **配置**: 自动修改openclaw配置文件，写入大模型API Key、endpoint等信息
- **更新**: 执行git pull → 依赖更新 → 重启服务
- **卸载**: 停止服务 → 删除安装目录 → 清理配置文件
- **启动**: 执行`openclaw dashboard`命令，展示访问地址

### 3. 企微集成模块
#### 自动集成
- Playwright启动浏览器访问企微管理后台
- 自动识别页面元素，完成智能机器人创建
- 自动获取机器人Secret并写入openclaw配置
- 引导用户输入匹配码完成最终配置

#### 手动集成
- 图文步骤指引用户手动创建机器人
- 表单收集用户填写的Secret等配置
- 自动写入配置并验证集成有效性

## 状态管理与持久化
### 全局状态机
定义标准化的安装流程状态机，确保流程可控可回溯：
```
初始状态 → 风险确认 → 信息收集 → 依赖检测 → 依赖安装 → openclaw安装 → 配置写入 → 集成选择 → 完成
```
- 每个状态转换都有明确的触发条件和验证机制
- 支持中断恢复：程序意外退出后重启可自动检测到未完成的安装流程，支持断点续装

### 状态持久化
- 安装进度、配置信息、操作日志定期加密写入本地配置文件
- 持久化文件存储在用户目录下，权限设置为仅当前用户可读
- 敏感信息使用操作系统级别的密钥管理加密：
  - Windows: Credential Manager
  - macOS: Keychain
  - Linux: libsecret

### 并发控制
- 实现全局操作互斥锁，同一时间只允许执行一个系统级操作（安装/更新/卸载/集成）
- 操作进行时禁用相关功能按钮，防止用户重复触发
- 支持操作取消功能，允许用户安全中断正在进行的操作，自动回滚到稳定状态

## 错误处理设计
### 错误分类
1. **可重试错误**: 网络下载失败、依赖安装超时 → 提供重试按钮，支持断点续传
2. **用户干预错误**: 权限不足、磁盘空间不足 → 明确提示用户手动处理，给出具体操作指引
3. **不可恢复错误**: 系统不兼容、未知异常 → 展示双层错误提示：
   - 外层：小白用户易懂的自然语言描述和解决方案
   - 内层（可折叠）：技术细节和完整日志，方便高级用户排查问题
4. **安装回滚机制**:
   - 所有修改先在临时目录进行，验证成功后再原子性移动到目标目录
   - 安装失败时自动清理所有已安装的文件和配置，恢复到安装前状态
   - 提供手动清理工具，用于解决极端情况下的残留问题

### 安全设计
#### 敏感信息保护
- 所有敏感信息(API Key、Secret、CorpId等)仅在本地内存和加密存储中处理，绝对不传输到任何第三方服务器
- 内存中处理完敏感信息后立即清理，避免内存泄漏导致信息泄露
- 日志系统自动脱敏所有敏感信息，防止日志泄露

#### 命令执行安全
- 所有系统命令执行必须使用`child_process.execFile`或`spawn`的数组参数形式，**绝对禁止使用字符串拼接**
- 对所有用户输入的路径、配置信息进行严格的白名单校验，过滤特殊字符和路径遍历攻击
- 限制命令执行权限，默认以普通用户权限运行，仅在必要时申请管理员/root权限，且明确告知用户

#### 软件来源安全
- 所有依赖软件（Node.js、git、openclaw等）均从官方源下载，预置官方哈希值列表
- 下载完成后自动校验文件哈希值，验证不通过则拒绝安装并提示用户
- 支持镜像源配置，同时校验镜像源文件的哈希值，防止下载劫持

#### Playwright自动化安全
- 自动化操作使用无痕浏览模式，操作完成后彻底清理所有浏览器数据、Cookie和缓存
- 禁止记录或上传用户的企微后台登录凭证、操作过程和任何页面内容
- 自动化脚本仅完成机器人创建和Secret获取功能，不执行任何其他页面操作

### 网络异常处理
- 实现断点续传功能，大文件下载中断后可以从断点继续下载，不需要重新下载
- 配置智能重试策略：临时网络错误自动重试3次，指数退避间隔
- 支持离线安装模式，允许用户预先下载所有安装包到本地目录，离线时自动使用本地安装包

## 用户体验优化
### 小白用户友好设计
- **极速安装模式**: 提供一键极速安装选项，默认同意所有协议，使用推荐配置，实现真正的零手动操作一键安装
- **智能引导**: 所有需要用户操作的步骤都提供图文并茂的引导，避免技术术语
- **错误提示分层**: 所有错误都有两层展示：
  - 外层：通俗易懂的自然语言描述和具体的解决步骤
  - 内层（可折叠）：技术细节和完整日志，供高级用户或排查问题使用
- **智能故障诊断**: 内置常见问题知识库，自动分析错误原因并给出解决方案
- **进度可视化**: 所有操作都有清晰的进度条、步骤说明和实时日志，让用户了解当前进度

### 高级用户功能
- **自定义配置**: 支持高级用户修改安装路径、依赖版本、镜像源等配置
- **配置导入导出**: 支持安装配置的导入导出，方便在多台机器上快速部署
- **日志导出**: 支持一键导出完整安装日志，方便问题排查和反馈
- **多实例管理**: 支持管理多个独立的openclaw实例，满足不同使用场景

## MVP范围
包含所有核心功能：
- 完整的首次安装流程（依赖检测安装→openclaw安装→企微集成）
- openclaw更新、卸载、启动功能
- 自动/手动两种企微集成方式
- 断点续装、错误回滚、敏感信息加密等安全特性
- 注册/登录页暂不实现，后续版本迭代加入
