# OpenClaw双模式安装方案设计

**日期**：2026-03-24
**版本**：1.0
**作者**：Claude

## 1. 背景
当前OpenClaw安装流程基于源码克隆编译方式，存在以下问题：
- 仓库地址配置错误（https://github.com/openclaw-ai/openclaw.git 不存在）
- 安装速度慢，需要git环境和编译过程
- 不符合官方推荐的npm安装方式

## 2. 目标
实现双模式安装，优先使用npm全局安装，失败时自动降级到源码安装，提高安装成功率和用户体验。

## 3. 整体架构
### 3.1 安装流程
```
开始安装
    ↓
检查依赖
    ↓
尝试npm全局安装openclaw → 成功 → 使用npm版本后续流程
    ↓ 失败
回退到git源码克隆安装 → 成功 → 使用源码版本后续流程
    ↓ 失败
安装失败，提示错误
    ↓
写入配置文件（适配不同安装方式的配置路径）
    ↓
启动服务（使用对应方式的启动命令）
    ↓
安装完成
```

### 3.2 两种安装方式对比
| 特性 | NPM全局安装 | 源码安装 |
|------|------------|----------|
| 安装速度 | 快 | 慢 |
| 依赖环境 | npm | git + npm |
| 配置路径 | ~/.openclaw/.env | [安装目录]/.env |
| 启动命令 | openclaw start | 安装目录下 npm start |
| 升级方式 | npm update -g @openclaw-ai/openclaw | 重新拉取源码编译 |

## 4. 核心功能设计
### 4.1 NPM安装模块
- **安装命令**：`npm install -g @openclaw-ai/openclaw@^0.1.0`（锁定主版本号，避免不兼容更新）
- **前置检测**：安装前先检测是否已存在全局openclaw，若版本符合要求则跳过安装
- **镜像复用**：使用depsManager中配置的npm镜像源，提高国内用户安装成功率
- **权限处理**：权限不足时自动尝试添加`--prefix ~/.npm-global`参数安装到用户目录，避免sudo/管理员权限要求
- **成功校验**：执行`openclaw --version`，返回版本号且版本兼容即表示成功
- **错误处理**：捕获所有安装错误，清理半安装的包，记录日志，触发降级流程

### 4.2 源码安装模块
- 修复仓库地址为：`https://github.com/openclaw/openclaw.git`
- 保留原有克隆、依赖安装、配置写入逻辑
- 作为降级方案，仅在npm安装失败时触发
- git从必填依赖改为可选依赖，仅在需要源码安装时检测

### 4.3 统一适配层
- **安装类型检测**：新增`detectInstallationType()`方法，优先检测npm安装，再检测源码安装；持久化安装类型到本地存储，避免重复检测
- **配置路径统一**：两种安装方式均使用`~/.dclaw/openclaw/.env`作为统一配置路径，避免路径差异问题
- **配置迁移**：首次安装时自动检测旧配置路径（~/.openclaw/.env 或 源码目录/.env），迁移到统一配置路径
- **服务启动适配**：根据安装类型自动调用对应的启动命令，统一环境变量传递和日志输出格式
- **全生命周期适配**：新增`update()`、`uninstall()`、`getServiceStatus()`等方法的适配逻辑，覆盖完整生命周期

### 4.4 冲突处理
- **版本冲突处理**：检测到多个安装版本时优先使用npm版本，提示用户清理多余版本
- **端口冲突处理**：启动前检测端口9600是否被占用，自动分配可用端口或提示用户
- **命令冲突处理**：优先使用本次安装的openclaw命令，避免全局命令冲突

### 4.5 错误处理与回滚
- npm安装失败时自动切换到源码安装，用户无感知
- 两种安装方式都失败时才返回安装错误
- 保留原有回滚机制，安装失败自动清理所有临时文件、半安装包和目录

## 5. 变更范围
### 5.1 需要修改的文件
1. `src/main/modules/openclawManager.js`：核心安装逻辑改造
2. `src/shared/constants.js`：更新OPENCLAW_CONFIG配置，添加npm包相关信息
3. `src/main/modules/depsManager.js`：确保npm在依赖检测列表中

### 5.2 新增方法
- `installViaNpm()`: npm安装实现
- `detectInstallationType()`: 安装类型检测
- `getConfigFilePath()`: 获取配置文件路径
- `startService()`: 统一服务启动接口
